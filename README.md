# Planuri cu sens

Pagină statică de prezentare pentru servicii de asigurare de viață, sănătate și planuri de investiții.

## Fișiere

- `index.html` — pagină și interacțiuni demonstrative
- `sergiu-alexe.jpg` — portret optimizat pentru pagină; metadatele fotografiei originale au fost eliminate

Deschide `index.html` într-un browser pentru previzualizare. Formularul de contact și statisticile de vizualizări/accesări sunt demonstrative și necesită servicii externe pentru colectare centralizată.
